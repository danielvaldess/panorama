- **Rama principal:** `main`. Trabajo por ramas `feat/*`, `fix/*`, `docs/*`.
- **Commits:** cortos y descriptivos (`feat:`, `fix:`, `docs:`, `chore:`).
- **Secretos:** nunca en el repo; usar variables de entorno (`.env`, ignorado).
- **Documentación:** el `README` refleja el estado real; `AGENTS.md` da contexto técnico.
